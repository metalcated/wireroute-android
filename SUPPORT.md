# WireRoute Support

WireRoute is a free, open-source WireGuard client for Android. It does not provide a VPN subscription, hosted VPN service, or RouterOS administration service. You need access to your own compatible WireGuard endpoint.

## Get help

- Follow the [secure RouterOS WireGuard setup guide](ROUTEROS_SETUP.md) for a guarded example.
- Search the [existing issues](https://github.com/metalcated/wireroute-android/issues) for a known problem.
- [Open a support request](https://github.com/metalcated/wireroute-android/issues/new) for app issues, feedback, or feature requests.
- Contact the maintainer through the [metalcated GitHub profile](https://github.com/metalcated).

When reporting a problem, include the WireRoute version and build number, Android version, device model, reproduction steps, expected behavior, observed behavior, and only the directly relevant sanitized log lines.

## Protect your secrets

GitHub issues are public. Never post private or preshared keys, RouterOS passwords, complete profiles or exports, QR codes, recovery data, or network identifiers you consider sensitive. Public keys are not secret cryptographic material, but they can identify a deployment.

For a suspected vulnerability, follow [SECURITY.md](SECURITY.md) rather than opening a detailed public issue.
