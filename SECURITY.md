# WireRoute Security Policy

## Reporting a vulnerability

Do not disclose a suspected vulnerability or exploit details in a public GitHub issue.

Use GitHub's [private vulnerability reporting form](https://github.com/metalcated/wireroute-android/security/advisories/new). If that form is unavailable, open a minimal [support issue](https://github.com/metalcated/wireroute-android/issues/new) asking the maintainer to establish a private contact channel, without including technical details or sensitive data.

Include the affected WireRoute version, Android version, impact, reproduction conditions, and a suggested remediation when available. Use generated test credentials and documentation-only addresses; never include live private keys, RouterOS passwords, or production profiles.

## Supported versions

Security fixes target the current development branch and most recent published Android version. Older builds may be asked to update before a report is investigated.

## Scope

This policy covers the WireRoute Android application, VPN-service integration, routing logic, profile handling, local activity storage, endpoint map, and diagnostics. Problems in a user-operated VPN endpoint, RouterOS installation, Android platform, or unrelated third-party service should be reported to that project's owner.
